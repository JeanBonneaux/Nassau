    Ce que montre la carte

    trajet calé : corrigé par le tour sur place qui l'a suivi trajet à l'estime : compté par le robot depuis le dernier calage tour sur place (le robot se recale sur le plan) correction : d'où le robot se croyait à où le calage le place contact du pare-chocs échos du capteur de distance (ce qu'il a vu devant lui) objet frôlé (capteurs optiques du pare-chocs) en plus pâle : contact ou objet frôlé lors d'un essai précédent destination ; pleine une fois atteinte base de recharge pièces inaccessibles (ton dessin) marge de l'estime : 2 cm + 4 % du chemin roulé depuis le dernier calage
